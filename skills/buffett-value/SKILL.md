# 巴菲特质量价值选股（buffett-value）

本技能实现 `docs/style-skill-contract.md` 契约 v1.0。

## 风格本质（与其他派的分歧点，判据须体现）

巴菲特买的是**"用合理价格买优秀公司"**——不追求最便宜，追求**长期资本回报的质量与可持续性**。他愿意为确定性付溢价，但对"讲故事的平庸公司"零容忍。因此本派的核心变量是：**ROIC 的持续性、护城河的方向（变宽还是变窄）、所有者收益的现金含量**。估值是第五关而非第一关。

## 执行前必读

1. `skills/shared/common-redflags.md` — 先跑红线，命中即 fail。
2. `references/moats.md` — 判 `moat` 维度前加载（五类护城河 + 变宽/变窄判据）。
3. `references/management-valuation.md` — 判 `management`/`valuation` 维度前加载。
4. `config/profiles/buffett-value.yaml` — 本次使用的阈值（可被 `profile_overrides` 覆盖，输出里注明实际生效值）。

**数值纪律**：所有 `hard_screen[].actual` 中的数值只能取自 `computed_metrics`。不得自行心算 PE/ROE/CAGR，不得把比率再乘一遍。若需要的指标 `computed_metrics` 里没有，写入 `data_gaps` 并标 `confidence:C`，**禁止估算**。

## 五关判据

### 第一关 · 能力圈（gate，不计分）
能否用三句话说清这家公司**怎么赚钱、赚谁的钱、钱从哪来**。说不清 → `verdict: fail`，`veto_hits` 记 `OUT_OF_CIRCLE`（注明是"我看不懂"而非"公司不好"）。

### 第二关 · 好生意（权重 25）

| id | 判据 | 默认阈值（见 profile） |
|---|---|---|
| roe_10y | 近10年 ROE 逐年均达标 | 每年 ≥15%，且无任一年 <8% |
| roic_min | ROIC 最低值（近似口径） | ≥12% |
| gross_margin_min | 毛利率最低值（周期行业可豁免） | ≥30%，或显著高于行业中位 |
| cash_conversion | FCF/净利 多年均值 | ≥0.8 |
| capex_intensity | 维持增长所需资本开支强度 | 定性：轻资产或再投资回报率高 |
| no_equity_dilution | 增长不靠持续增发 | 定性 + RF-07 交叉；股本 3 年增速取 `growth.shares_3y_growth_pct` |

**关键追问**：这家公司提高价格时，销量会不会掉？会掉的不是好生意（商品型），不会掉的才有特许经营权特征。

### 第三关 · 护城河（权重 25）
按 `references/moats.md` 给 `moat` 维度 1–5 分，并**必须单独回答方向**：过去 5 年变宽/持平/变窄，未来 3 年预判。方向比绝对水平更重要——护城河变窄的便宜货是价值陷阱。

### 第四关 · 管理层（权重 20）
按 `references/management-valuation.md`，三个必答：
1. **承诺兑现**：找 2–3 条 3 年前的公开承诺/指引，对账实际结果。
2. **资本配置**：赚到的钱去了哪（再投资 ROIC？并购溢价？回购价位？分红持续性？）。
3. **股东导向**：薪酬结构、减持记录、关联交易。
诚信问题 → 命中 RF-05 直接 fail，不给"其他项很高分"的机会。

### 第五关 · 安全边际（权重 30）
1. 用 `computed_metrics.valuation` 的 PE/PB/股息率摆出当前价格水平。
2. 三情景粗估内在价值区间（乐观/中性/悲观），**只做区间与方向，不做精确 DCF 假装严谨**；如需严谨 DCF，应升级到专门的估值技能而非本筛选技能。
3. 给出建议介入价：中性内在价值 × (1 − 要求的安全边际)。
4. **反向检查**：当前股价隐含了什么样的增长假设？这个假设现实吗？

## 打分与三值

- `score` = Σ(各关加权得分)，0–100。
- `verdict`：
  - `pass`：五关全过，且无 confidence C 的关键维度。
  - `gray`：护城河方向或管理层有实质疑问，或关键数据缺失导致某一关无法判定。
  - `fail`：任一硬指标关不过 / 命中红线 / 估值严重透支（中性情景下仍高于内在价值）。
- 禁止输出"建议关注、需权衡"这类和稀泥结论。要么 pass，要么说清挂在哪一条。

## 输出

严格按契约 JSON 结构返回。`one_line` 示例格式：
`"ROE 10年逐年达标+护城河变宽，但当前PE 32x无安全边际 → fail（第五关）"`

末尾固定附：本结论为 AI 研究性意见，不构成投资建议。
