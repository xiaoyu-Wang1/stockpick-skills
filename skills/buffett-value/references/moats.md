# 护城河判据（Buffett 视角）

## 五类护城河及验证方法

| 类型 | 本质 | 可验证信号 | 常见误判 |
|---|---|---|---|
| **无形资产**（品牌/专利/特许） | 定价权与准入门槛 | 提价后销量与份额不降；专利到期前后收入结构；牌照数量与审批趋势 | 把"知名度"当品牌。知道≠愿意多付钱。验证只看**价格溢价能否持续** |
| **转换成本** | 换供应商的代价 > 收益 | 客户留存/续约率；实施周期与迁移费用；收入中"存量续费"占比 | 用"粘性强"这种词替代数据。要找到留存率或续费比的具体数值 |
| **网络效应** | 用户越多价值越大 | 双边/多边活跃度、GMV 集中度、头部聚集趋势 | 单边的"规模大"不是网络效应。要看跨边增长的相关性 |
| **成本与规模优势** | 同等质量下成本更低 | 毛利率长期高于同行且差距稳定；单位成本随规模下降曲线 | 周期性低成本 ≠ 结构性成本优势。要看穿越一轮周期后差距是否仍在 |
| **聚焦规模**（高效规模） | 市场只容得下少数玩家 | 行业玩家数量与历史整合路径；新进入者融资与失败记录 | 把"行业集中"当护城河。集中也可能是寡头共谋式脆弱均衡 |

## 强度与方向（每次必答）

```
moat 强度 1–5：
1 = 无明显护城河，靠周期或运气
2 = 单一弱护城河，可被资本复制
3 = 单一强护城河，或两类弱护城河叠加
4 = 两类以上强护城河互锁
5 = 结构性垄断/生态级，替代方案会显著恶化用户体验

moat 方向（比强度更重要）：
变宽信号：份额持续提升、定价权增强（提价后销量不降）、新护城河类型正在形成（如从成本优势长出网络效应）、客户结构向高转换成本迁移
变窄信号：核心产品价格战、监管削弱准入壁垒、技术路线切换使既有优势失效、客户议价力上升（大客户集中度提高）、管理层开始靠并购维持增长
持平：需给出"为什么这轮 5 年没变化"的解释，不接受默认持平
```

## 经济商誉视角（巴菲特/《财报分析与投资》一脉）

问：**这家公司账面上最有价值的资产，是不是没在资产负债表上？**（品牌、客户关系、员工熟练度、选址）
- 若是 → 低净资产可能高 ROE，正常；不要用 PB 高判定"贵"。
- 若不是 → 高 PB 就是给有形资产付溢价，需要极强的增长来兑现，风险大。

判断方法：ROE 与 PB 的组合。ROE 高 + PB 高 = 商誉存在且市场已定价；ROE 高 + PB 低 = 少见机会，重点复核数据真实性；ROE 低 + PB 高 = 最危险组合。

## 特许经营权 vs 商品型业务

一句话自检：**"如果它明天消失，竞争对手多久能填补？"**
- 6 个月内可填补 → 商品型（commodity），定价权来自成本曲线，给估值要按周期股。
- 3 年以上难填补，且用户/客户会明显受损 → 特许经营权（franchise）。
