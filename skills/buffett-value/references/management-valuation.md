# 管理层评估与估值纪律

## 一、管理层三维评估

### 1. 承诺 vs 兑现（最硬的一维）
找 2–3 条 **3 年前**的公开表述（年报致股东信、业绩会指引、定增/并购说明中的预期），逐条对账：

| 承诺 | 当时表述 | 实际结果 | 偏差 | 事后解释是否可信 |
|---|---|---|---|---|

评分口径：兑现率 100%（超额需谨慎看是不是靠一次性因素）> 基本兑现 > 部分兑现 > 大幅落空且主动说明 > 大幅落空且改口径/沉默。
**最后一档（落空且沉默/改口径）是本派最强负面信号**，比落空本身更值得警惕。

### 2. 资本配置纪律
逐年回答：赚到的钱去了哪？回报如何？
- **再投资**：增量 ROIC 是否 ≥ 存量 ROIC？（增量低于存量 = 边际回报在衰减，规模增长不等于价值增长）
- **并购**：溢价倍数、业绩承诺完成度、商誉余额变化、整合后毛利率走向
- **回购**：回购价位 vs 当时内在价值区间（高价回购 = 摧毁价值，这是巴菲特反复强调的）
- **分红**：连续年数 + 在亏损年是否收缩（稳定分红反映现金真实性）
- **囤积现金**：净现金占市值过高且无使用计划 → 折价理由，也是潜在催化

### 3. 股东导向与制度迫力
- 薪酬：是否与 ROIC/长期指标挂钩，还是与营收规模/股价挂钩
- 减持：实控人与高管的减持时机（利好发布前后减持是强负面）
- 关联交易与资金占用：年报"关联方及交易"章节，看必要性与定价依据
- 制度迫力（institutional imperative）检查：管理层是否在盲目跟随同行扩张、被"别人都在做"驱动

## 二、所有者收益（Owner Earnings）口径

```
所有者收益 ≈ 净利润 + 折旧摊销等非现金项 − 维持现有竞争地位所需的年均资本开支
```
实操用 `computed_metrics.cash_and_quality.owner_earnings_latest`（近似：OCF − capex）。
判读：
- 所有者收益 ≥ 净利润 → 会计利润有现金支撑（优）
- 所有者收益 < 净利润且长期如此 → 利润被应收/存货/资本开支吸走，警惕"纸面繁荣"
- 需要持续远超折旧的 capex 才能保住份额 → 表面赚钱、实际不给股东赚钱

## 三、估值纪律（第五关）

### 允许的粗糙
本技能是**筛选**，不是估值建模。三情景用"合理倍数 × 中性业务假设"给区间即可，明确标注为粗略区间。若用户需要严谨 DCF，应交回编排层升级到专门估值技能。

### 三情景最低要求
```
乐观：营收 CAGR 上限 + 毛利率历史高位倍数
中性：近年趋势延续 + 行业中位倍数
悲观：份额或价格受损 + 估值向历史低位回归
```
每档必须写清**假设**，不接受只给一个目标价。

### 安全边际与介入价
```
要求安全边际（见 profile，默认 25%）
建议介入价 = 中性内在价值 × (1 − 要求安全边际)
```
并做**反向 DCF 粗检**：当前市值隐含了未来 N 年什么样的增长？该增长是否已在 `hard_screen` 的能力范围内可实现？若隐含增速高于历史最高增速，直接判"估值透支"。

### 与"好公司"的冲突处理（本派最容易被问到时出错的地方）
```
好公司 + 贵：       fail 或 gray，理由写"第五关不过"，不否定前四关
坏公司 + 便宜：     fail（本派不为便宜买平庸）
好公司 + 合理价：   pass
```
不要因为"公司很好"就放松估值，也不要因为"很便宜"就忽略生意质量。把哪一关挂了写清楚，就是本派报告的价值所在。
