# 公共一票否决红线（Common Red Flags）v1.0

被所有风格技能在判据前共同加载。**命中任一条 → verdict 直接为 fail，写入 veto_hits，不再计算分数。**
风格自有否决项写在各 SKILL.md 里，与本文件叠加生效。

| ID | 红线 | 判据口径 | 数据来源要求 |
|---|---|---|---|
| RF-01 | 审计意见非标准无保留 | 最近一期年报为保留/否定/无法表示意见 | 年报审计报告原文 |
| RF-02 | 持续经营存疑 | 财报出现"与持续经营相关的重大不确定性"段落，或 `quality_flags.going_concern=true` | 年报原文 |
| RF-03 | 大股东高比例质押 | 控股股东质押比例 > 50% | 交易所公告/中国结算 |
| RF-04 | 财务真实性重大嫌疑 | 存在被监管处罚的财务造假记录，或 Benford 检验/毛利-现金流长期严重背离且无解释 | 处罚公告 + 双源财务数据 |
| RF-05 | 管理层诚信污点 | 实控人/核心高管存在侵占上市公司利益、重大违规减持、失信被执行记录 | 裁判文书/监管公告 |
| RF-06 | 商誉或减值地雷 | 商誉占总资产 > 30%，或近 2 年单次减值 > 净利润 50% | 年报附注 |
| RF-07 | 股权稀释失控 | 近 3 年总股本因增发/可转债增长 > 40%，且 EPS 未同步增长 | `computed_metrics.growth.shares_3y_growth_pct` + 股本变动公告 + EPS 序列 |
| RF-08 | 信息不透明 | 关键财务数据无法从两个独立来源核验（数据缺失≠造假，但无法核验则降级 confidence 而非否决） | `sources` 字段 |

## 使用纪律

1. 红线判定必须给出**证据出处**，不接受"感觉有风险"。
2. RF-08 的边界：数据查不到时，正确动作是标注 `data_gaps` 并把 `confidence_grade` 降到 C、倾向输出 `gray`；**不要**为了显得严格而误判为 fail。
3. 红线是"排雷"，不是"选股"。通过红线不等于符合任何风格标准。
