# 彼得·林奇 GARP 选股（lynch-garp）

本技能实现 `docs/style-skill-contract.md` 契约 v1.0。

## 风格本质（与其他派的分歧点）

林奇的核心是 **"这个价格买这个成长速度，划不划算"**（PEG 思维），外加两条本框架其他风格没有的特色：
1. **先分类再评判**——不同类型公司用完全不同的标准（把增长股的 50% 增速期待套在银行股上是外行行为）。
2. **一句话故事**——如果你不能用一句话向 12 岁小孩讲清为什么买它，就别买。
林奇比费雪更"平民"：接受信息劣势，靠常识观察 + 快速核验；也比巴菲特派更能容忍中小公司与冷门股。

## 执行前必读

1. `skills/shared/common-redflags.md` — 先跑红线。
2. `config/profiles/lynch-garp.yaml` — PEG 阈值、分类判据、负债上限等。

**数值纪律**：PEG/PE/增速取 `computed_metrics.valuation.peg` 与 `growth.*_cagr_pct`。注意脚本的 PEG 用的是**保守口径（净利与营收 CAGR 取较低者）**，不要换成更漂亮的那一个。存货/应收膨胀检验直接引用 `growth.inventory_cagr_last_pct`、`growth.receivables_cagr_last_pct` 与 `growth.revenue_cagr_last_pct` 三者对比（字段为 null → 进 `data_gaps`，该判据记"无法判定"，不得凭印象给分）。

## Step 1 · 分类（本派独有，必须先做）

| 类型 | 识别特征 | 本派怎么评 |
|---|---|---|
| 缓慢增长型（2–4%） | 成熟公用事业类 | 林奇明确回避，除非股息极高 → 通常直接 fail |
| 稳定增长型（10–12%） | 大型消费/医疗龙头 | 看 PEG 与估值修复机会，别期待十倍 |
| 周期增长型 | 汽车/化工/航运/半导体设备/资源 | **必须在周期中部或底部买**，看 PE 高（周期差）还是低（周期好）——本派最容易反向出错的一点 |
| 快速增长型（20%+） | 中小成长、连锁、平台 | 林奇的主战场。看增速空间与"扩张还能持续几年"，警惕过早见顶 |
| 转型困境型 | 濒临破产/重组 | 看现金能否撑住、重组是否落地；风险高但回报不对称 |
| 隐蔽资产型 | 账面下有未被定价的资产（土地/牌照/股权/矿/门店） | 需要估值重估的催化剂，与格雷厄姆派有交集 |

`hard_screen` 第一项必须是 `ly0_classify`，写明类型 + 判断依据。**分类错 → 后面全错**，若类型证据不足则直接 `gray`。

## Step 2 · 判据

| id | 判据 | 默认口径 |
|---|---|---|
| ly1_peg | PEG | ≤ 1.0 优；1.0–1.5 可接受（gray 倾向）；> 1.5 视为贵 |
| ly2_debt | 负债率（分类型差异化） | 一般 D/A ≤ 25%；稳定增长型可 ≤40%；金融/公用事业另行判断（本派不套用同一标准） |
| ly3_margin | 毛利率与净利率趋势 | 稳定或上升；林奇极重视"存货增速不得超过销售增速" |
| ly4_institutional | 机构持股与关注度 | 越低越好（冷门溢价）；机构持仓 >70% 且一致看多 → 加分项失效 |
| ly5_insider | 内部人增持 | 近 6–12 个月有实控人/高管增持为佳；高管在利好后减持扣分（与 RF-05 交叉） |
| ly6_earnings_quality | 盈利质量 | 剔除一次性收益后的"真实 EPS"是否仍达标；存货/应收增速 vs 营收增速 |
| ly7_growth_runway | 增长还能持续多久 | 定性必答：还能开多少家店/拿多少订单/渗透率还有多少空间 |

## Step 3 · 一句话故事检验（林奇纪律，硬性）

必须写出：
```
"我买它，因为 <客户/使用者/场景> 在 <做什么动作>，
 而这件事 <多久内> 会让 <收入/利润> 增长 <多少>，
 当前 PEG <数值> 意味着市场 <还没有/已经> 定价这件事。"
```
写不出、或写成"受益于行业景气度提升"这类空话 → **verdict: fail**，`veto_hits` 记 `STORY_UNCLEAR`。

## Step 4 · 十要素快速打分（可选，做灰度调节）

林奇《战胜华尔街》的自检项，作为 `qualitative` 补充：业务是否无聊/起怪名字（加分，冷门）、有无内部人购买（加分）、机构是否少（加分）、有无存货堆积（减分）、是否被媒体高度关注（减分）、盈利是否靠一次性项目（减分）。

## 打分与三值

- PEG 相关占 40 分，分类正确性与匹配占 15 分，负债/盈利质量 25 分，冷门度/内部人 20 分。
- `pass`：分类明确 + PEG ≤ 1.0 + 故事清晰 + 无 ly6 红旗。
- `gray`：PEG 1.0–1.5，或周期股但位置不明，或增长持续年限讲不清。
- `fail`：PEG > 1.5 / 分类错配预期 / 故事空话 / 存货应收异常膨胀 / 靠一次性收益。

## 输出

按契约 JSON 返回，`id` 用 `ly0_classify…ly7_growth_runway`。`qualitative` 里必须有 `category` 维度（值取六类之一）。
`one_line` 示例：
`"快速增长型(新开门店120家/年)，PEG 0.8、存货增速低于营收、机构持仓仅9% → pass"`

末尾固定附：本结论为 AI 研究性意见，不构成投资建议。
