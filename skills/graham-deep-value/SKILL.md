# 格雷厄姆深度价值选股（graham-deep-value）

本技能实现 `docs/style-skill-contract.md` 契约 v1.0。

## 风格本质（与其他派的分歧点，必须体现）

格雷厄姆买的是**"价格与价值的差额"**，不是"公司有多好"。他的第一原则是**不亏钱**，第二原则是记住第一条。因此：
- 本派对**估值的苛刻程度远超巴菲特派**，愿意买"平庸但极便宜"的公司。
- **不要求护城河、不要求高 ROE 持续性、不要求成长**。一家 ROE 10% 但价格低于清算价值的公司，本派可以 pass；一家 ROE 25% 但 PE 40x 的公司，本派必然 fail。
- 与巴菲特派的分歧是真实分歧，不要试图调和：这正是编排层汇总矩阵的价值。

## 执行前必读

1. `skills/shared/common-redflags.md` — 先跑红线。本派额外注意 RF-06（商誉地雷）：净流动资产口径必须剔除商誉与无形资产。
2. `config/profiles/graham-deep-value.yaml` — 阈值。

**数值纪律**：PE/PB/股息率取 `computed_metrics.valuation`；本派需要逐年盈利序列判"波动性"，取 `computed_metrics.per_year`。**禁止**自行用市值/净资产重算 PB（已由脚本算好）。

## 七条硬指标（防御型投资者，可执行化）

| id | 判据 | 默认阈值 | 说明 |
|---|---|---|---|
| g1_size | 足够企业规模 | 市值 ≥ 100 亿（A股口径，见 profile） | 排除小微公司的信息不足与流动性风险 |
| g2_financial_strength | 财务稳健 | 总负债/总资产 ≤ 65%，且流动比率 ≥ 1.5 | 原版为"长期负债不超过净流动资产"，本框架用更稳健的比率口径 |
| g3_earnings_stability | 盈利稳定 | 近 10 年**无年度亏损** | 数据不足 10 年 → confidence 降级、倾向 gray |
| g4_dividend_record | 连续分红 | 连续 ≥ 20 年派息（无记录则用"连续 ≥10 年 + 有分红"降级判定并声明） | 原版要求 20 年 uninterrupted |
| g5_earnings_growth | 盈利增长 | 近 10 年 EPS 累计增长 ≥ 1/3（≈3.4% CAGR） | 取 `computed_metrics.growth.eps_cumulative_growth_pct`；基期 EPS≤0 时为 null → 记"无法判定"并入 data_gaps（本派此时倾向 gray 而非放行） |
| g6_pere | 适度市盈率 | PE ≤ 15（近 4 季度或 TTM） | 取 `computed_metrics.valuation.pe` |
| g7_pe_pb | 市盈率×市净率 | PE × PB ≤ 22.5，且 PB ≤ 1.5 | 取 `computed_metrics.valuation.pe_x_pb` |

**七条全过 → pass。** 挂 1 条 → gray 或 fail，取决于挂的是哪条：
- 挂 g6/g7（估值类）→ **fail**。估值是本派的存在理由，不可妥协。
- 挂 g1（规模）→ fail（本派明确排除小规模公司）。
- 挂 g2/g3/g4/g5（质量类）但估值极便宜 → **gray**，写明"防御型标准不达标，仅在 NCAV 口径下值得复核"。

## 加分层：烟蒂股（NCAV）检验

对通过七条或估值极便宜的标的追加：
```
净流动资产 NCAV = 流动资产 − 总负债（全部负债，不只长期）
调整后 NCAV = NCAV − 商誉 − 无形资产（必须剔除，否则虚高）
市值 / 调整后 NCAV < 0.66 → 触发"烟蒂"标记（格雷厄姆原口径 2/3）
```
若 `computed_metrics` 未提供 NCAV（当前版本确实不提供），**必须**在 `data_gaps` 声明"NCAV 需人工从资产负债表科目复核"，不得凭印象给出该比率。此时可基于 `data_pack.financials` 逐年 `current_assets` / `total_liab`（比率近似可引用 `per_year` 的 `current_ratio` 与 `debt_to_assets_pct`）做粗略方向判断，confidence 定 B。

## 本派的价值陷阱防护（不做护城河判断，但必须做这个）

格雷厄姆派最大的亏损来源是**"便宜是因为该便宜"**。因此本技能虽不评护城河，但必须回答三问（写入 `qualitative`）：
1. **便宜的原因是什么？**（周期顶部回落 / 一次性损失 / 行业结构性衰退 / 管理层问题 / 纯粹市场忽视）
2. **有没有催化剂让价值回归？**（回购、分红提升、资产重组、行业供需反转、清算/私有化）
3. **会不会一直便宜下去？**（"价值陷阱三件套"：主业萎缩 + 无回购无分红 + 行业被替代）
   三问的答案若指向"结构性衰退且无催化剂" → **verdict: fail**，理由写"低估值来自基本面不可逆恶化，安全边际为假"。

## 打分与三值

- 硬指标 7 条占 80 分（每条按重要性加权，见 profile），价值陷阱防护占 20 分。
- `pass`：七条全过 + 非价值陷阱。
- `gray`：估值达标但质量类有 1 条不过，或催化剂不明。
- `fail`：估值不达标 / 规模不达标 / 判定为价值陷阱。

## 输出

按契约 JSON 返回，`id` 用 `g1_size…g7_pe_pb` + `g_trap`。
`one_line` 示例：
`"PE 8.2×PB 0.9=7.4 远低于22.5，连续14年分红，但主业连续3年萎缩且无回购 → fail（价值陷阱嫌疑）"`

末尾固定附：本结论为 AI 研究性意见，不构成投资建议。
