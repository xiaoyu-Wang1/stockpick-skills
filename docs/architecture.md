# 架构与演化路线

## 分层与依赖方向

```
orchestrator（编排层）
    ↓ 只依赖契约，不依赖任何风格细节
style skills（风格层）──→ shared/（公共红线，被所有风格引用）
    ↓ 只依赖数据格式，不依赖数据来源
data pack + metrics.py（数据与计算层）
    ↓
adapters（数据源适配，Phase 2）
```

**依赖只能向下**。风格技能永远不许 import 另一个风格；编排层永远不许内嵌某风格的判据。违反这条 = 演化性破产。

## 三条工程不变量（改动前先背下来）

1. **契约不变**：输入/输出 JSON 结构（`docs/style-skill-contract.md`）是主干接口。升级走 `contract_version` 字段，旧版技能可被标记拒收而不是静默出错。
2. **计算与判断分离**：凡是"数"，出自 `metrics.py`；凡是"判"，出自 SKILL.md。新需求想加指标 → 加进 metrics.py；想加标准 → 加进 references。两者混写是本项目最容易出现的腐化方式。
3. **判据即文档**：任何阈值必须出现在 `config/profiles/*.yaml` 并在输出中注明实际生效值；任何定性标准必须出现在 references 文件里。禁止只存在于"AI 的临场理解"。

## 为什么用 Skill 而不是代码（及边界）

| | Skill(Markdown) | 代码(Python) |
|---|---|---|
| 改判据成本 | 改文字 + 跑 eval | 改代码 + 测试 + 回归 |
| 定性判断 | 擅长（护城河方向、管理层诚信） | 无法表达 |
| 数值严谨 | 差（LLM 心算不可靠）→ 所以外包给 metrics.py | 擅长 |
| 全市场批量 | 慢、贵（token 线性增长） | 快、便宜 |
| 结果可复现 | 中（三值制 + 固定 schema 收敛） | 高 |

**正确用法**：代码做漏斗前段（万级→百级，纯数值筛选），Skill 做后段（百级→十几只，需要定性判断）。这也是 ai-berkshire / ai-hedge-fund 共同的实践边界——本框架把它显式写进契约，而不是靠自觉。

## 演化路线（详细版，替代 README 里的四行）

### Phase 2 · 数据自动化
- 实现 `adapters/akshare.py` 等，输出严格符合 `data-contract.md`，附字段缺失声明。
- 加 `metrics.py --batch`，一次算完整池，把计算成本从 LLM 侧移到本地。
- 数据缺失策略标准化：缺 10 年数据时，是"降级 confidence"还是"跳过该判据"，必须由 profile 显式配置（现在是各 SKILL 自行声明）。

### Phase 3 · 用回测反向演化 Skill（本框架真正的复利来源）
1. 把历史某日的股票池跑一次全风格 → 存 `verdict/score` 作为信号快照（含 `skill_version`）。
2. 对每个信号统计 6/12/24 个月相对基准的超额收益；按风格、按 verdict 分层统计命中率。
3. 找出"系统性错判"的判据（例：某条硬指标 pass 的组反而跑输）→ 修订 references 措辞或调 profile 阈值 → 升 minor 版本 → 跑 `evals/` → 记录 `evals/results/`。
4. 每轮演化都留下 `skill_version` 与实验记录，形成可审计的判据进化史。**这一步是本框架与"prompt 合集"的分水岭。**

### Phase 4 · 风格委员会
- 编排层增加仲裁步骤：≥3 派一致 → 高置信；意见分裂 → 输出"分歧解释"（谁对谁错取决于哪一条假设成立）。
- 引入"派系权重"：按 Phase 3 的实盘/回测命中率动态调权，而不是拍脑袋。
- 支持自定义风格技能（第三方贡献）：契约 + evals 是唯一门禁，不审代码只审输出合规与判据可追溯。

### 长期
- 风格库扩展：段永平（商业模式本分）、芒格（逆向与偏误）、Druckenmiller（宏观动量）、 shareholder-friendly（分红回购治理派）。每个都是"新目录 + 新 profile"，零主干改动。
- 数据源扩展：财报原文解析（doc-image-scan/file-read 类能力）替代二手指标。
- 交付形态：HTML 选股看板（data-visualization skill）替代 JSON 矩阵。

## 失败模式清单（本项目会踩的坑，提前记账）

| 坑 | 症状 | 防线 |
|---|---|---|
| 判据漂移 | 同一个风格今天评护城河、明天忘了 | references 固定章节 + evals E4 |
| 数值幻觉 | 报告里出现 metrics 里没有的数 | 契约"禁止心算" + E3 校验 |
| 风格调和 | 汇总层把 4 派分数平均排名 | 编排层"跨风格不可比"硬约束 |
| 阈值万能主义 | 换牛市后原阈值全 pass 无区分度 | profile 可覆写 + Phase 3 回测校准 |
| 成本失控 | 300 只全量跑深度分析 | Step 2 预筛 + 分批声明（编排层强制） |
| 数据源单点 | akshare 字段变更导致全池数据错 | `sources` + 市值校验 + 双源纪律 |
